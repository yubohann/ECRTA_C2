## Table C: 失败链审计（贡献 1 数据）

- 结构：单机单目标重复（cubicle/4 B0 早期 run：277 失败中 258 次同一 (fid,goal,mv)；R1 REACH run：425/431）。
- 频率：B0 cubicle R1=285/10 runs（单 run 链最长 258）；R2=73/10 runs；open/2 R1=17、R2=3。

## 结论（论文主张）

1. 失败链真实、可量化、可抑制；抑制类机制（B1/SVR）在链格子将其降至近零。
2. **REACH（跨机证据 + 中心风险）在 open/2 上显著改善 makespan**（R2 −8.65s vs B1, p=0.005；两轮一致），在 cubicle 上中性——分配级风险反馈在低失败/大任务格子有收益。
3. **SVR 是最稳定的机制**：4 批次 40 runs 中 39 完成，A* 失败总和仅 61。
4. **STEER 无收益**；其"全冷却保持"变体在 cubicle 显著增加 makespan（+9.4s, p=0.005）——设计教训：确认阻塞后应继续选择其他候选或保持轻量重试，而非空等。
5. B1 抑制在低失败格子有 ~2-5% 的开销（open/2 两轮均慢于 B0）。
6. 实例方差主导 makespan（同法 run 间 60-140s），n=10 检验力有限；更大 n 与可控失败诱导协议为后续工作。
