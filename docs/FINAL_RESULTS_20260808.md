## 结论（二次修正后，诚实）

1. **没有任何方法取得统计显著的 makespan 改善**。
2. **REACH 在 open/2 方向一致占优**（非显著趋势），在 cubicle 中性。
3. **SVR 复用机制实际生效**（全实验 80 次复用）——此前"复用从未触发"的表述错误，已更正；但复用未带来显著收益。
4. **轨迹规划失败是新报告的指标**：与 A* 失败同数量级（R1 cubicle B0=289/B1=382；R2 cubicle B1=383）——B1 抑制 A* 失败的同时轨迹失败仍多（执行层第二类失败，值得单独分析）。
5. 失败链审计（结构/频率/抑制）与"同 seed 407 vs 0"可复现性证据保持成立。
6. 论文统计口径（写进方法节）：
   - makespan：部分完成 run 按 180s 截断（summary 字段只覆盖完成者，需截断）；
   - traj 失败：从原始遥测 traj_result 统计（summary 从未携带该字段）；
   - SVR 复用：按 gate 事件 decision 字段统计；
   - 检验：bootstrap CI + 符号置换 + Mann-Whitney U 置换（实例非真配对）。
