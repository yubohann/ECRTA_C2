## 2. 失败链定性（证据更新）

- failures.jsonl 目标坐标 z≈1.25（视点高度）→ **失败发生在"局部视点"层**，不是任务单元顶点层；
- 论文 INVALID 只过滤"任务级不可达区域"；**即使 INVALID 存在，视点级不可达也不被覆盖**；
- 发布版无 INVALID → 任务级不可达也会漏出到执行层；
- 结论：425 次重复失败**大概率是真实存在的执行层现象**（视点级+任务级漏出），
  但**频率与分布受代码版本（无 INVALID）影响**——v1 中"伪现象"判断被推翻。
