# PRCT-C2 投稿判断

## 判断规则

1. 若 B3 相对 B1 的成对中位 improves >= 10%，或未完成率 improves >= 20pp，且 p90/RMST 不恶化，才可保留 takeover 主张。
2. 若 B3 未超过 B1，主方法不能投稿 takeover。
3. 若 B1 相对 B0 有稳定收益，可以改写为“重复失败抑制 + 可达性证书”，但需要更多 UAV 数和通信范围证据。
4. 若证据不足，保留负结果，不强行投稿。
