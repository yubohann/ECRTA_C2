## 1. 论文真实方法（原文提取，作为对照基准）

### 1.1 任务表示（IV-A）
- 粗网格分解（scale = Lg）→ 网格内 CCL 分割 free/unknown 区域 → 每区域 anchor=体素平均位置
- **任务单元 = 每个空间不相交的未知区域**（连通分量），未知顶点 Vu 为拓扑代表
- 状态机：PENDING / COMPLETED / **INVALID**（CCL 识别仅连未知区域的不可达区，从分配排除）
- Ti 结构：pu,i（顶点位置）、Hi（2D 凸包，若拆分）、gi（父网格 ID）、NUMi（未知体素数=工作量）、di（无人机 ID）
- 连通图 G=(Vf∪Vu, Ef∪Eu∪Ep)：restricted A* 生成边

### 1.2 连续性分配（IV-B）
- CVRP：容量 Di=NUMi，容量约束 ΣD_i x ≤ σQ·W/Nc，**σQ=1.1**（V-A）
- 代价矩阵 Ccvrp：Cd,T（机-任务）、CT（任务-任务）
- CT(i,j)=ψ(ρij)·lij；ρij=lij/Rc，**Rc=λc·Lg，λc=1.2**
- ψ(ρ)=1（ρ≤1）；1+(ρ−1)²（ρ>1）——**图邻接连续性惩罚**
- 遍历代价 lij：hybrid A*（A*vox 若 d<dthr，否则 A*graph(Π(pi),Π(pj))）——**dthr 未在论文给出，需查代码**
- Commit 式分配协议：Proposal→Commit→Finalize→Cancel（版本化、超时回滚）

### 1.3 单机 CP 规划（IV-C）
- 全局：分配任务单元上的 ATSP（LKH），边含**速度一致性惩罚**（Eq.6-8：Tij=lij/vm + Σ[(vm−|v̂k|)²/(2vm am) + 2|v̂k|/am·H(−v̂k)]）
- 局部：前沿聚类（PCA）→ 视点采样 → 覆盖最多前沿体素的代表视点 → 任务单元内局部 TSP → B-spline

## 2. 纠正计划（分步执行）

### 步骤 A：参数与机制核对（代码 vs 论文）——目标：逐项确认或找出差异
A1. 核对 launch/代码参数：σQ、λc、Lg（网格尺度）、dthr、top_view_num、感知范围 10m、MID360 模型、vmax/ωmax/amax、rcomm=5m
A2. 验证连通图机制：代码中 CCL/INVALID/连通图构建是否真实执行（grep + 运行日志/遥测中任务单元结构）
A3. 验证任务单元真实性：统计任务单元（Ti）的数量、体积分布、状态（PENDING/COMPLETED/INVALID）——确认"任务单元=连通未知区"而非网格中心
A4. 判定：任一参数与论文不符 → 修正配置重跑；机制未生效 → 定位代码 bug

### 步骤 B：论文基线复现——目标：Cubicle/4≈50.9s、Open/4≈43.0s（±20% 内可接受，同环境）
B1. 用对齐后的参数跑 Cubicle/4 × 10、Open/4 × 10（180s 上限应足够，论文 ~50s）
B2. 记录探索时间、总路径长度、平均速度、完成率
B3. 判定：
- 达标（±20%）→ 基线可信，继续步骤 C
- 不达标 → 逐项排查（版本漂移、动力学/传感器参数、LIO、地图共享、INVALID 失效），直到达标或记录为环境限制

### 步骤 C：失败链真相调查——目标：解释 425 次重复 A* 失败
C1. 在正确基线上重测失败链频率：若 INVALID 生效，重复失败应基本消失
C2. 若仍存在：检查失败目标是否为 INVALID 任务/连通图外区域/局部规划边界条件
C3. 判定：伪现象（配置/代码）→ 修复后基线重验；真现象 → 才值得作为论文问题

### 步骤 D：重新定位改进点——原则：以论文方法为锚，不与论文已有机制重叠
D1. 候选方向必须满足：
- 不改三张地图/传感器/动力学/通信协议/评价指标（保持）
- 不与论文已解决的问题重叠（INVALID 过滤、连续性惩罚、连通表示、commit 协议）
- 有论文或近作中未被覆盖的明确缺口（如：λc 固定 vs 自适应、σQ 固定 vs 在线校准、任务单元工作量预测 vs 事后、通信约束下的地图共享调度）
D2. 从论文自身局限出发（原文 Future Work：主动连通性维护、定位感知映射/漂移鲁棒协作）+ 我的实测数据（正确基线上）重新筛选
D3. 新方向需先通过机制审计（事件>0）再进入成对实验
