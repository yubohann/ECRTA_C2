# 文献轮 ROUND-3 记录（2026-08-08，线上学习后更新）

## VORL-EXPLORE 全文精读（arXiv 2603.07973，HTML 全文已读）

### 机制细节（已核实）
- execution fidelity p_i,t = σ(wᵀz+b)，z∈R⁸：局部拥挤（半径内队友数）、短时 stuck 标志、到前沿的归一化距离、可行动作比、机器人/目标周围未知区比、四邻阻塞密度、**planner 可行性标志（A* 是否返回有效动作）**。
- 分配层：Φ_i[f] = u_t[f] − λ(p)·d_i[f] − ρ(p)·r_i[f]（fidelity 越高 λ/ρ 越小，效用主导；越低越偏近距低冲突）。λ(p)=λ0+λ1(1−p)。
- 执行层：双阈值 τ_H/τ_L + 驻留 K 的滞回门控，在全局 A* 引导与反应式 RL 策略间切换；**恢复覆盖（RecoveryOverride）**：规划不可行/停滞 W 步/切换振荡 → 对称破缺机动后恢复。
- 自监督：Q = ω_cov·Δcov + ω_dist·Δdist − ω_risk·risk − ω_stall·stall；伪标签 y=𝟙{Q≥0}；BCE+在线更新。
- 实验：40×40/80×80 栅格 100 runs；Gazebo 工厂 4 机；报告 SR/EL/Overlap；动态障碍 8-128 个。
- 假设：同步共享地图、理想通信。

### 与我们的差异（论文定位关键）
| 维度 | VORL-EXPLORE | 我们 |
|---|---|---|
| 失败模式 | 动态拥堵/交互（随时间变化） | **静态不可达**（open_set_exhausted，地图不动） |
| 信号 | 预测式（学习门） | **实测证据**（A* 失败事件，确定性可审计） |
| 分配器 | Voronoi + BFS 距离 | C2 的 ACVRP/LKH 连续性分配 |
| 执行层 | A*/RL 仲裁 + 恢复机动 | 确定性目标选择（保持/确认/轮换） |
| 学习 | 需要训练（PPO + 门） | 无学习，零训练 |

结论：我们的贡献面成立——"静态不可达前沿导致的重复失败链"是 VORL 未覆盖的失败模式；我们用实测证据替代学习预测是合法差异。**但必须引用 VORL 并明确：其"把执行可行性反馈进分配"的大方向我们不是首创。**

### 借鉴点（R3 实现）
1. VORL 的 stuck/可行性标志是"学习特征"——我们的是真值证据，论文可写"deterministic counterpart"。
2. VORL 的恢复覆盖（不可行→不空等→做别的）支持 STEER v3：全冷却时不应空等（v2 hold 被证有害），应回到有界重试（B1 语义）。
3. VORL 用连续信号调制分配成本——支持 REACH 中心级风险的做法；其评估场景（动态）与我们（静态）互补。

## SC-RRT（arXiv 2503.17005v2，2025）
- "traversability checks during RRT expansion and global RRT pruning upon map updates eliminate unreachable frontiers"——**最接近"消除不可达前沿"的工作**；目标为低成本 SLAM 机器人（2D），序列化目标选择避免振荡 + 路点回溯。
- 引用价值：我们的"失败链→抑制/证据"与它"消除不可达前沿"同题，但我们针对 C2 多机 ACVRP 流水线且用实测证据而非 RRT 可通行性检查。
