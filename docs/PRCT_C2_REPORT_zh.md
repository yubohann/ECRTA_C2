# PRCT-C2 实验报告

状态：Octa/4 UAV 主配置已跑完，本稿为最终实验记录。

## 1. 项目与方法

- B0：原始 C2。
- B1：重复 A* 失败抑制和冷却。
- B2：B1 + 只读 peer 可达性证书。
- B3：B1 + 证书 + 事件触发 peer takeover。

固定：三张 C2 官方地图、LiDAR 探索任务、传感器、动力学、通信、LKH/ACVRP、终止条件和指标。

## 2. 环境

- WSL2 Ubuntu 20.04，ROS Noetic，RTX 4090。
- NLopt 2.7.1，LKH 3.0.6。
- OpenGL 4.6 到 3.3 的 WSLg 兼容补丁已披露，不算算法贡献。

## 5. 门槛

- G0 可审计运行：通过。
- G1 重复不可达失败链：通过。
- G2 peer 可达样本：通过。
- G3 证书可靠性：机制层通过。
- G4 端到端收益：未通过。
- G5 无退化：未通过。

## 6. 结论

1. B1 重复失败抑制在 Open 场景收益明确。
2. B3 相对 B1 在三图均无稳定增量；Octa 为 5胜8负、中位慢 2.58s。
3. G4/G5 未通过，PRCT takeover 主方法不能投稿。
4. 若继续投稿，应改为重复失败抑制或负结果。

## 7. 有效性威胁

- 无官方随机种子协议。
- FINISH 是本地规则，不是论文全局覆盖指标。
- 覆盖率、碰撞、通信断连尚未完整提取。
- 只有三条主配置，不是完整 2/3/4 UAV 和通信范围矩阵。
