## 偏差与限制

- repeated instance 标签不是官方随机种子；B0/B1/B1+ 在同一标签下仍存在明显随机差异，成对比较不能视为严格同种子配对。
- 无失败实例上 v4 与 B1 行为不应有实质差异，但 makespan 仍波动，说明随机初始状态是主要噪声源。
- 失败链本身不稳定：5 组中仅 2 组达到连续 3 次失败阈值，机制覆盖不足。
- 所有方法均 5/5 FINISH，当前配置未制造出足够失败压力。
- 正式投稿前需要先在失败链可复现、同初始状态的协议下重新验证；否则不能下统计结论。
