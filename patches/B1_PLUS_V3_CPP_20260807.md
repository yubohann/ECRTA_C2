# B1+ v3 代码修改说明

## 1. 目的

把 B1+ 从 v2 的“失败链指数退避等待”改为“失败确认目标隔离”：同一目标连续达到
prct_repeat_threshold 后，在当前 frontier map epoch 内不再重新选中该目标。
v2 在 open_plan_office / 3 UAV / 5 m / n=5 中没有端到端收益，因此不再使用等待式退避。

## 2. C++ 修改

文件：

- src/swarm_exploration/exploration_manager/include/exploration_manager/c2_exploration_manager.h
- src/swarm_exploration/exploration_manager/src/c2_exploration_manager.cpp

主要变更：

- isPrctTargetCooled()：当 prct_backoff_enabled=true 时，只要 repeat_count 大于等于
  prct_repeat_threshold 且 map_version 等于当前 epoch，即返回 true，不检查冷却到期。
- prctFailureCooldownS()：隔离模式下返回 std::numeric_limits<double>::max()，
  v3 不依赖时间退避。
- registerPrctFailure() 遥测增加 quarantine_enabled，隔离模式 backoff_s=-1。
- updateFrontierStruct() 在 map epoch 变化时清理旧 epoch 的隔离记录，使目标仅在
  frontier viewpoint 集合变化后重新允许评估。
- 候选全部隔离时增加 prct_all_cooled_fallback，并回退到原始 C2 最近合法目标，避免空转。

## 3. 脚本修改

- run_b1plus_batch.sh：B1/B1+ 隔离说明更新为 map-epoch quarantine。
